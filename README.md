# Basic HTML & CSS Webpage

A simple web project demonstrating fundamental HTML5 structure and CSS styling, including class/ID selectors, inline styles, text styling, and styled external links.

---

## 📁 Project Structure

```text
├── index.html   # Main HTML document containing structured text and links
└── style.css    # External stylesheet applying background colors, font sizes, and text colors
🎨 Features & Key Concepts
HTML Structure:

Semantic heading elements (<h1>, <h2>, <h3>).

Text paragraphs (<p>) with targeted inline <span> elements for custom text coloring.

An unordered list (<ul>) containing navigation links (<a>) pointing to popular external websites (Facebook, Google, Twitter).

CSS Styling:

Global Styling: Sets a brown background for the page body and white color for paragraphs.

Class Selectors (.head): Applies consistent styling across heading tags.

ID Selectors (#bglime, #para): Demonstrates higher specificity for unique background colors and font resizing.

🚀 How to Run
Clone or download this repository to your local machine.

Ensure both index.html and style.css are in the same folder.

Open index.html in any modern web browser (Chrome, Firefox, Edge, Safari).
